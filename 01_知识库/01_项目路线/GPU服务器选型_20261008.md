## 模型规模与训练方式

以下是工程规划，不是上游官方最低显存表。假设单卡小批次、输入约256–512 token、BF16、梯度检查点、梯度累积；GRPO先用少量训练样本和每提示4个候选。LoRA需要额外适配，新SID token的embedding/output层也要能学习。

| 阶段 | 建议显存 | 说明 |
|---|---:|---|
| 现有约0.33M参数TIGER、SASRec、MiniLM、RQ-VAE | 24GB足够宽裕 | 可在同一台机器顺序完成 |
| 约13M参数TIGER结构实验 | 24GB | 仍远小于B级LLM；具体batch要实测 |
| MiniOneRec 0.5B SFT+简化GRPO | 24GB起 | 全参数SFT；GRPO降低batch和候选数，必要时LoRA |
| MiniOneRec 1.5B LoRA SFT | 24GB起 | 与全参数训练分开标注 |
| MiniOneRec 1.5B全参数SFT+简化GRPO | 48GB优先 | GRPO参考模型、候选生成缓存会增加显存 |
| MiniOneRec 3B LoRA SFT+简化GRPO | 48GB优先，80GB更宽裕 | 全参数训练建议80GB并实测 |
| MiniOneRec 7B QLoRA SFT | 24–48GB，48GB优先 | 需要量化/PEFT代码适配，不能直接照跑原脚本 |
| MiniOneRec 7B简化RL | 80GB优先或多卡 | 仍取决于PEFT、序列长度、候选数与生成服务配置 |
| 上游完整大批次复现 | 4–8张80GB A100/H100级GPU | README的复现配置；论文SFT用8张H100 |

MiniOneRec并非仅仅换成更大的TIGER：其流程为冻结文本编码、SID构建、预训练Qwen2.5-Instruct上的多任务SFT、推荐奖励GRPO。上游SFT脚本默认8进程、有效batch1024、microbatch16；RL脚本默认8进程和16个候选。单卡需要调整训练配置和代码，保留方法核心但不宣称完整复现。

论文文本编码器是Qwen3-Embedding-4B；可以先用本地MiniLM和SID学习整个流程，再单独做编码器替换实验。推理计算内容向量与训练推荐LLM不是同一显存需求，分阶段执行。

来源：[MiniOneRec仓库](https://github.com/AkaliKong/MiniOneRec)、[论文训练设置](https://arxiv.org/html/2510.24431v1#S4)、[SFT脚本](https://github.com/AkaliKong/MiniOneRec/blob/main/sft.sh)、[RL脚本](https://github.com/AkaliKong/MiniOneRec/blob/main/rl.sh)。

## 为什么不能只看B数

BF16推理权重约为每参数2字节，但训练还有梯度、Adam状态、激活、临时张量。常规混合精度Adam示例可达到每参数18字节再加激活；实际BF16优化器和量化实现不同。GRPO还可能保留参考模型和多候选缓存。因此7B权重约14GB，不代表24GB可全参数训练。

来源：[Hugging Face GPU内存说明](https://huggingface.co/docs/transformers/main/en/model_memory_anatomy)。

## 软件与迁移

- Linux Ubuntu 22.04、Python 3.11；CUDA版PyTorch和与GPU兼容的驱动。
- 当前Windows虚拟环境不能直接复制到Linux；需要重建环境。
- 现有TIGER/RQ-VAE训练脚本没有完整device参数，先补模型/数据迁移和GPU评测路径，再试跑；本次尚未进行这项修改。
- MiniOneRec单独建环境，不能直接把上游锁定依赖混进当前环境。5090/PRO6000需特别核对较新的CUDA/PyTorch及扩展兼容性。
- 全流程用持久化数据盘存储数据、权重、日志，定期回传；tmux运行训练，训练代码负责选模与早停。
- 单张48GB不等于两张24GB自动合并；普通DDP每卡仍保留完整模型，只有正确配置分片才能降低单卡占用。

## 费用示例与行动顺序

以下只是租用时长乘单价，不是训练耗时预测，不含额外存储：

| 配置 | 开机10小时 | 开机24小时 |
|---|---:|---:|
| AutoDL 4090（首页价） | 18.80元 | 45.12元 |
| 矩池云4090（市场价） | 22.00元 | 52.80元 |
| 矩池云A6000（市场价） | 28.50元 | 68.40元 |
| AutoDL A800（首页价） | 55.90元 | 134.16元 |

1. 按时租单卡，验证SSH、GPU环境和存储。
2. 先迁移TIGER，固定数据和评测协议，训练到验证指标稳定。
3. 先做Qwen2.5-0.5B的SID/文本对齐SFT，评估后再做少量GRPO。
4. 再逐步升级1.5B、3B；按显存峰值和吞吐决定换48GB/80GB。
5. 用“达到同等训练目标的总费用”比较4090、A6000、5090，不能只凭纸面TFLOPS判定性价比。
