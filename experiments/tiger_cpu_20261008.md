# 小型 TIGER 首轮 CPU 实验

这是一轮个人简化实现实验：复用固定第三方 RQ-VAE 和 T5 模型，独立适配四段 SID、共同样本、确定性检索和评测。
不声称复现 TIGER 论文成绩。模型按验证 NDCG@10 选择，测试在选定之后执行一次。

- 参数量：328,320；训练轮数：3；最佳轮：3。
- 停止原因：`requested_epochs_completed`；总运行时间：202.6 分钟。
- 每轮有效下一物品样本：397,345；CPU 线程：2。
- 文本编码：冻结 MiniLM，384 维，最多 128 token；缺元数据 28 件。
- 超出截断上限的商品文本：20,645件，占 79.72%；优先保留标题、品牌和分类。
- RQ-VAE：3×256 码本，32 维隐空间；第 30 轮重建验证最佳。
- 三段 ID 重复比例：21.49%；最大碰撞组：34；最终 SID 全部唯一。

每人一个下一商品目标，所以 HR=Recall。相同用户、目录、用户内时间切分、完整历史过滤和最近20件商品输入。
生成模型使用全目录前缀树、固定 beam=20；属于有限 beam 近似搜索，SASRec 属于逐商品精确打分。
生成概率在限制合法 token 之前计算，不按合法分支重新归一化；训练四段 token 交叉熵，不另采商品负例。
测试 86,713 用户；输出不足20件的用户 0；返回商品合法率 100.00%。
推理批大小 32，预热后批次 P50/P95 0.153/0.363 秒；这不是单请求线上延迟。

单种子、首轮小模型，未做 beam 敏感性、超参数搜索或严格全局时间评测。商品文本使用固定完整目录，不使用留出评论或行为共购图。
完整配置、逐轮验证、指纹和编码/RQ-VAE 统计见同名 JSON；用户记录、SID映射、原始数据和权重均留在忽略目录。
