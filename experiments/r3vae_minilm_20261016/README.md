# MiniLM R³ VAE量化结果

2026年10月16日完成30轮CPU量化训练，模型294,944参数，耗时191.47秒。输入为已有冻结MiniLM 384维商品向量；32维MLP、参考方向与三层256码字产生三段SID，再追加第四段消歧。

训练目标为余弦重构，SC/PD正则权重为0。AdamW学习率5e-4、weight decay 1e-5、batch size 512、seed 2026；以1,295件目录向量验证集的重构损失选择第30轮。向量训练子集24,603件，初始化从中抽取最多4,096件做逐层残差MiniBatchKMeans。
