# MiniLM SID → Qwen 全参数 SFT 对照

冻结 MiniLM 生成商品向量，分别使用梯度更新和 EMA 更新的 RQ-VAE 生成四段 SID，再训练 Qwen2.5-1.5B-Instruct。两版推荐模型均为 **1,544,870,912 参数**，商品编码器和量化器在 SFT 阶段固定。

| 指标 | 梯度 SID | EMA SID | EMA 相对变化 |
|---|---:|---:|---:|
| Recall@10 | 0.093677 | 0.092870 | -0.86% |
| NDCG@10 | 0.075496 | 0.074639 | -1.13% |
| Recall@20 | 0.108819 | 0.106466 | -2.16% |
| NDCG@20 | 0.079319 | 0.078065 | -1.58% |

**本次 EMA 版四项推荐指标均略低，未取得下游收益，梯度版继续作为主基线。** 第一层活跃码字从 84 增至 117、有效码字数从 60.25 增至 84.98、三段碰撞余量从 21.49% 降至 17.08%，说明码本分配更充分，但这些离线改善没有转化为更好的 Recall/NDCG。后续 SID 方案仍以推荐结果检验。

MiniLM 为冻结的 6 层、384 维编码器。两版 RQ-VAE 均为 384→256→128→32 编码器、三层 256×32 码本与逆向解码器；三段量化码追加一段消歧码。Qwen 为 28 层 Decoder、hidden1536、12 个 Q 头 / 2 个 KV 头、FFN8960；扩展词表 152689，输入输出 embedding 共享。
